# Implementation Codemap

**Last Updated:** 2026-07-26

File-by-file structure. Types and their invariants are in `data.md`; the
component and epoch diagrams are in `architecture.md`.

## Root module -- `github.com/sshaplygin/as-cache`

No external dependencies. `testify` is test-only.

| File | Responsibility |
| --- | --- |
| `doc.go` | package documentation (the pkg.go.dev landing page) |
| `interfaces.go` | `Cacher`, `CacheStats`, `Policy`, `Bandit` |

| `errors.go` | sentinel errors returned by the constructor |

| `epoch.go` | epoch loop, bandit reporting, policy selection |
| `shadow.go` | promote/demote, shadow duty, value dropping, switch |

### Call graph, hot path

```go
Get(key)                       // cache.go
  sampler.sampled(key)         // sampling.go
  [shadows].Get(key)           // measurement only
  activePolicy.Get(key)
  recordActiveSample(hit)      // cache.go, atomic counters
  // gradual window only: promoteLocked -> migration.go
```

### Call graph, control plane

```go
runAdaptiveSelect()            // epoch.go, background goroutine
  runEpoch()
    closeMigrationLocked()     // shadow.go -> demoteLocked
    selectPolicyLocked()       // epoch.go
      policy.GetStats/ResetStats
      bandit.RecordStats       // every arm, active included
      bandit.SelectPolicy
    allowSwitchLocked()        // stability.go
    switchLocked(from, to)     // shadow.go
      promoteLockedCapacity(to)
      migrateData(from, to)    // migration.go
      activePolicy = to
      demoteLocked(from)
```

### Things that look wrong but are deliberate

- `selectPolicyLocked` reports the **active** policy from `activeSampledHits`,
  not from its own counters, so every arm is judged on the same substream.
- `demoteLocked` rewrites entries to the zero value in `Keys()` order rather
  than purging: that preserves LRU recency and leaves LFU relative order intact.
- `Advice.Epochs` comes from `reportingEpochs`, not `epochID`. The capacity gate
  can skip measurement for many ticks, and reporting those as evidence would
  overstate it.
- `AdaptedCache.Resize` replays *every* entry and lets the rebuilt cache evict.
  `Keys()` order is not portable (2Q returns frequent-then-recent, ARC returns
  recent-then-frequent), so no "keep the tail" rule is correct for both.

## `lfu` -- O(1) LFU

| File | Responsibility |
| --- | --- |
| `lfu.go` | thread-safe wrapper, eviction callbacks |
| `simplelfu/lfu.go` | core algorithm, frequency buckets |
| `internal/list.go` | doubly-linked list per frequency bucket |

Invariant: every bucket in `evictList` holds at least one entry, and `minFreq`
always addresses a live bucket while the cache is non-empty. Entry removal
funnels through `detach`/`recomputeMinFreq`. `Add` refuses entries at zero
capacity.

## `policies` -- ready-made arms

Depends on the root module, `lfu`, and `hashicorp/golang-lru/v2` (held at
**v2.0.6**; v2.0.7 builds too, see `CLAUDE.md`).

| File | Provides |
| --- | --- |
| `adapters.go` | `NewLRU`, `NewLFU`, `NewTwoQueue`, `NewTTL`, `NewRandomPolicy` |
| `adapt.go` | `PartialCacher`, `AdaptedCache`, `Adapt` |
| `random.go` | `RandomCache`, from scratch |
| `ttl.go` | `TTLCache`, own expiry over plain LRU |
| `conformance_test.go` | shared contract suite every policy must satisfy |
| `regression_test.go` | guards for specific past defects |

`Adapt` exists because 2Q and ARC both lack `Resize` and report neither
evictions nor removals. `TTLCache` does **not** use `expirable.LRU`: that type
returns `(zero, true)` for an expired-but-unreaped entry, pads `Values` with
zeros, and leaks a reaper goroutine per cache.

## `policies/arc` -- patent isolation

One file wrapping `hashicorp/golang-lru/arc/v2` through `policies.Adapt`.
Separate module so that importing `policies` never pulls in a patented
algorithm. Do not merge it into `policies` for convenience.

## `policies/tinylfu` -- W-TinyLFU

Wraps `maypok86/otter/v2`. Natively resizable, so unlike the adapted policies it
never rebuilds and keeps its frequency sketch. `Len()` is **approximate**
(otter reports an estimate), so the `EvictPartialCapacityFilling=false` capacity
gate may not fire; set it true when this arm is in play.

## `metrics` -- observability

Standard library only. `Advisor` is an interface rather than a generic
parameter so any `AdaptiveCache[K, V]` satisfies it. `Publish` registers an
`expvar.Func` (evaluated on scrape) behind a mutex plus a `recover`, because
`expvar.Get` then `expvar.Publish` is check-then-act and expvar panics on a
duplicate name.

## `bench` -- evidence (internal, never tagged)

| File | Provides |
| --- | --- |
| `workload.go` | deterministic zipf/uniform/loop/scan/phase-shift generators |
| `trace.go` | loaders for Twitter, LIRS and ARC trace formats |
| `bandit.go` | Thompson (Beta posteriors, discounted) and greedy bandits |
| `harness.go` | `Replay`, `Result`, `FixedPolicies`, tables |
| `evidence_test.go` | policy comparison, sampling-fidelity sweep |
| `timeline_test.go` | `ActivePolicy()` plot over a phase shift |
| `memory_test.go` | memory multiplier and allocations |
| `tuning_test.go` | epoch/migration configuration sweep |
| `trace_test.go` | real-trace evidence + parser self-tests |

Evidence tests are guarded by `testing.Short()` and excluded from `make test`,
which passes `-short`. Under `-race` epoch pacing changes enough to make the
measurements meaningless. Run `make evidence`.

The root module ships no `Bandit`; `bench/bandit.go` has one short enough to
copy.

## Entry points

What to call, per module. Methods on these types are deliberately not
enumerated here -- `go doc` is authoritative and always current.

```go
// root
ascache.NewAdaptiveCache(policies, bandit, settings) (*AdaptiveCache, error)
ascache.NewCache(cacher, policyType, size) *CacheWrapper   // wrap your own

// policies
policies.NewLRU / NewLFU / NewTwoQueue(size) (Policy, error)
policies.NewTTL(size, ttl) Policy
policies.NewRandomPolicy(size) Policy
policies.Adapt(size, build) (*AdaptedCache, error)          // adapt your own
policies.NewRandom(size) *RandomCache                       // concrete types
policies.NewTTLCache(size, ttl) *TTLCache

// separate modules
arc.NewPolicy(size) (Policy, error)
tinylfu.NewPolicy(size) (Policy, error)

// lfu
lfu.New(size) (*Cache, error)
lfu.NewWithEvict(size, onEvicted) (*Cache, error)

// metrics
metrics.Take(cache) Snapshot
metrics.Publish(name, cache) error
```

## Build and checks

```bash
make all             # fmt, vet, lint, test, release-check
make test            # go test -race -short, every module
make evidence        # replay workloads, print the comparison tables
make release-check   # licence + unresolvable sibling requires
make lint            # golangci-lint v2, shared root config
```
